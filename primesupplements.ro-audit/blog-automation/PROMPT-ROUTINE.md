# Instrucțiunile automatizării (Routine)

Routine: **Blog Prime Supplements 2 articole pe zi** · zilnic la 06:57, ora României (`CRON_TZ=Europe/Bucharest 57 6 * * *`) · o sesiune nouă la fiecare rulare · **conector necesar: Shopify** (adăugat de proprietar din interfață).

Sesiunile automatizării nu au acces la repository: ghidul și calendarul sunt citite din **Shopify Files** (`blog-automatizare-ghid-redactional*.txt`, `blog-automatizare-calendar*.txt`). La o modificare, urcă în Files o versiune nouă cu același nume (Shopify poate adăuga un sufix); automatizarea folosește mereu fișierul cel mai nou.

Pozele principale ale articolelor sunt generate cu Google Gemini (secțiunea 4b din ghid). Cheia se pune în setările mediului cloud ca variabilă `GEMINI_API_KEY`; fără ea, automatizarea folosește poza produsului.

Each run writes and schedules educational Romanian blog articles about the store's supplements, so that they rank in Google, get cited by AI search engines (Google AI Overviews, ChatGPT, Perplexity) and convince readers to order. The owner asked for exactly this; do not ask questions, just do the run and report. Quality matters more than speed: take the time to research the product facts and to write a genuinely useful article.

SETUP
1. Load the Shopify tools with ToolSearch: "select:mcp__Shopify__graphql_query,mcp__Shopify__graphql_mutation,mcp__Shopify__run-analytics-query,mcp__Shopify__validate_graphql_codeblocks,mcp__Shopify__graphql_schema". If they are unavailable, stop and report that the Shopify connector is missing.
2. Read the rules and the calendar from Shopify Files (this session has no git repository). Use the newest blog-automatizare-ghid-redactional*.txt (the editorial guide, Markdown) and the newest blog-automatizare-calendar*.txt (the calendar, JSON) (Shopify may add a suffix to the file name); download them with curl and read them completely. Current versions: https://cdn.shopify.com/s/files/1/0917/5138/3415/files/blog-automatizare-ghid-redactional_926a5330-9dca-4729-8f3f-1e86aa55c3d2.txt?v=1791916932 and https://cdn.shopify.com/s/files/1/0917/5138/3415/files/blog-automatizare-calendar.txt?v=1791911877 . If the files cannot be read, stop and report it.

WHAT TO CREATE
3. Today = `TZ=Europe/Bucharest date +%F`. Candidate entries are calendar rows with "data" <= today + 1 day whose "handle" does not exist yet in Shopify (check each with the Admin API: articles(first:1, query:"handle:<handle>")). Process them in calendar order: normally the 2 rows of tomorrow (they get their calendar date and hour, 09:00 or 18:00 Europe/Bucharest, converted to UTC for publishDate). If rows from earlier days are missing (a run failed), create those too, at most 4 articles in this run in total; an overdue row gets the next free slot (today 18:00 if still in the future, otherwise the next day's free slot that is not used by the calendar). Skip a row whose main product is not ACTIVE and say so in the report.
4. If no calendar rows are left, plan 2 new articles yourself per guide section 2: one of the 15 focus products listed there (the one with the fewest new articles in the last 30 days first), an angle not used before, and no overlap with existing titles or intent: tags. Schedule them at 09:00 and 18:00 Europe/Bucharest on the first day after the latest scheduled or published article. Never write about clothing or accessories.

FOR EACH ARTICLE
5. Read the facts via the Admin API: the products (title, handle, status must be ACTIVE, descriptionHtml, featuredImage url and altText, the Judge.me metafields reviews.rating and reviews.rating_count if present), the collection (title, handle), and the published articles of blog news (title, handle, tags, image url, summary; paginate). Use only product facts from the product page. Never state prices.
6. Write the article in Romanian with correct diacritics (ș ț with comma), 1,200-1,800 words, following the guide: answer first, a clear definition with the main keyword in the first 100 words, quotable opening sentences under each H2, short paragraphs, a table where it helps, a practical "Cum folosești <produs>" section with the dose from the label, real objections answered, the product box twice (after the answer section and before the FAQ), FAQ with 4-6 questions phrased like real searches, collection link, the standard supplement disclaimer, the exact author box, "Articole Similare" with 2 existing related articles (their real image.url). ## Rutina de rezervă (model mai ieftin)

Routine: **Blog Prime Supplements – rezervă (model mai ieftin)** · zilnic la 13:57 și 21:57, ora României (`CRON_TZ=Europe/Bucharest 57 13,21 * * *`) · model `claude-sonnet-5-5` · o sesiune nouă la fiecare rulare · **conector necesar: Shopify** (adăugat de proprietar din interfață, ca la rutina principală).

Cerința proprietarului: dacă rularea principală eșuează, articolele se fac pe un model mai ieftin, ca să nu rămână nicio zi fără postare. Rezerva verifică întâi, ieftin, dacă articolele de azi și de mâine din calendar există deja în Shopify. Dacă există, se oprește imediat. Dacă lipsește ceva, le creează doar pe cele lipsă, după aceleași reguli și același ghid, fără să dubleze vreun articol. Raportul ei începe cu „Rezervă:”.
